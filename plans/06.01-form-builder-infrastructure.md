# Phase 06.01 — Form Builder: Infrastructure & Shared Lib

## Goal

Set up the shared library code (API wrappers, edit tracker) and route stubs that all form builder pages depend on. No UI yet.

## Steps

### 1. Create `src/lib/form.ts`

Thin API wrappers using `apiFetch` from `src/lib/api.ts` and auto-generated types from `src/lib/api.types.ts`:

```ts
export async function getForms(token: string): Promise<FormListResponse>
export async function createForm(token: string, data: FormCreateRequest): Promise<FormResponse>
export async function getForm(token: string, id: string): Promise<FormResponse>
export async function updateForm(token: string, id: string, data: FormUpdateRequest): Promise<FormResponse>
export async function deleteForm(token: string, id: string): Promise<void>
export async function generateQuestions(token: string, prompt: string, conversationId?: string | null, currentState?: LLMFormData | null): Promise<LLMResponse>
```

Each follows the `apiFetch(path, token, init?)` pattern.

### 2. Create `src/lib/editTracker.ts`

Diff tracking for AI context — port from v1 with minimal changes:

```ts
export interface FormSnapshot {
  title: string
  description: string
  questions: FormQuestionInput[]
}

export function buildEditsSummary(before: FormSnapshot, after: FormSnapshot): string
export function computeEditCounts(before: FormSnapshot, after: FormSnapshot): { additions: number; removals: number; edits: number }
```

### 3. Add `sonner` dependency

```bash
pnpm add sonner
```

### 4. Create route stubs

```
src/app/(app)/forms/new/page.tsx
src/app/(app)/forms/[id]/edit/page.tsx
```

Each exports a minimal `"use client"` component rendering a placeholder heading.

### 5. Verify

```bash
pnpm dev
```

- `/forms/new` renders (placeholder)
- `/forms/123/edit` renders (placeholder)
- No TypeScript errors in `src/lib/form.ts` and `src/lib/editTracker.ts`
